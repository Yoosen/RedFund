## 问题修复

- 修复历史净值接口失效导致旧交易长期停留在「待确认」状态的问题：历史净值改为多数据源级联获取（优先东方财富 JSON 接口，失败时回退到走势图接口与旧版 HTML 接口），并在匹配失败时自动重试，确保净值稳定回填。
- 严格按交易日期匹配对应交易日净值，避免错配到邻近交易日，提升持仓成本与收益计算的准确性。
- 修复关闭自动更新检查后主界面仍提示「发现新版本 / 需要下载」的问题：关闭自动更新即完全静默，不再提示已检测到的新版本、已是最新、检查失败等信息，仅保留用户已主动发起的下载 / 安装进度提示。

## 功能优化

- 净值业绩走势图移除多笔购入标记，改为仅显示一条持仓成本参考线（虚线）与当前成本点位，走势更简洁直观。
