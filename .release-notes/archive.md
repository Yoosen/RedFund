# 发布归档

## v1.0.2 - 2026-08-19

### 其他变更

- 新增「资产分布」甜甜圈图：按基金类型（股票型 / 指数型 / 混合型 / QDII / 债券型 / 货币型 / 其他）对持仓市值分组，分类按占比从高到低排列。鼠标悬停时对应扇区高亮、其余扇区淡化，并跟随鼠标指针在右下方浮出气泡展示类型、金额与占比（与图例一致的两位小数格式）。
- 新增基金类型识别 `FundType`：按官方 FTYPE 字段映射，在建仓 / 加减仓 / 转换 / 当日新增及手动刷新时抓取一次（行情刷新不再更新），并在主面板手动刷新时对存量持仓回填类型。

### 问题修复

- 修复 QDII 收益归属错位：QDII 基金（净值 T+1/T+2 披露）的当日收益现归到其净值更新当日，而非交易当日，避免收益日历与累计收益曲线出现错位的橙色待确认点。
- 修复收益日历在单只基金行情缺失时整体放弃记录的问题：改为仅跳过该基金（其对当日收益贡献本为 0），仅当所有活跃持仓行情均缺失时才不记录；同时确保当前交易日的本地实时计算优先覆盖已有记录，使当天收益日历与实时收益口径一致。
- 修复关闭自动更新后主界面仍提示「发现新版本 / 已是最新 / 检查失败」的问题：关闭自动更新即完全静默，仅保留用户主动发起的下载 / 安装进度提示。

### 功能优化

- 当日新买表单交互优化，录入更顺手。

## v1.0.1 - 2026-08-08

### 新功能

- 累计收益曲线支持鼠标悬停：移动鼠标实时显示垂直参考线、高亮数据点，以及该日的日期、累计收益、当日收益率与累计收益率。
- 收益曲线时间范围新增「1周」选项，可查看近 7 天收益走势与区间收益。
- 基金详情页改版：历史净值移入「净值业绩走势」页签，十大重仓股移入「盘中预估实时涨跌」页签，不再在底部一并平铺展示，改为跟随对应页签联动展示。
- 净值业绩走势页签切换近1月/近3月/近6月/近1年/近3年区间时，走势图上方新增展示相应区间的涨跌幅。

### 功能优化

- 收益曲线纵坐标补充累计收益率小字；隐藏金额模式下收益率仍可正常显示。
- 收益曲线左上角改为展示「区间收益」（区间内净赚金额），数值随所选区间变化，并按盈亏红绿着色。
