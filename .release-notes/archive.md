# 发布归档

## v1.0.3 - 2026-08-27

### 新功能

- **本地搜索**：基金列表支持本地关键词搜索（名称 / 代码），无需联网即可快速定位持仓。
- **小倍养基估值（暂不稳定）**：接入「小倍养基」估值数据源（`XiaobeiQuoteService` + `XiaobeiSessionStore`），作为东财估值之外的补充估算来源，提升盘中估值覆盖与稳定性。
- **估值准确率评估**：新增 `EstimationDeviationRecorder`，记录每只基金历史估值与最终净值的偏差，在详情页展示估值准确率评估，帮助用户判断估值可信度。

### 功能优化
- **关联标的展示（优先场内 ETF，跟踪指数兜底）**：
- 详情页尾部新增「关联标的」卡片：优先展示基金关联的**场内 ETF**（如 000216 → 518880 黄金ETF华安、004253 → 518800 黄金ETF国泰），走场内 ETF 实时市价涨跌；
- 无关联场内 ETF 的品种（如跟踪 AU9999 的商品基金）回落展示**跟踪指数**当日涨跌幅。
- **前十大重仓股涨跌幅**：
- 重仓股卡片独立成卡并遵循 `Equatable`，打开/刷新时避免整列重建抽帧；
- 重仓股实时涨跌幅支持北交所股票。
- **重仓数据动态补充**：详情页按「时点槽」动态补充重仓涨跌幅（普通基金 15:00 后、QDII 08:00 后自动补一次），用户主动刷新时强制绕过节流补拉。

### 问题修复
- **关联 ETF / 跟踪指数误显示脏数据**：
- **北交所重仓股涨跌幅不展示**：
- **指数刷新降频**：大盘指数报价与涨跌家数各自独立节流（报价 20s、涨跌家数 60s），减少非必要请求。
- **详情页滚动性能**：重仓 / 估值区块加 `.equatable()` 隔离重建，加载态未变化区块不再整列重建，消除下滑抽帧。

### 其他变更
- 新增关联标的字段，并持久化到磁盘缓存。
- 新增重仓股 / 行业 / 资产配置数据模型，支持本地缓存与静态数据过期判定。

## v1.0.2 - 2026-08-19

### 其他变更

- 新增「资产分布」甜甜圈图：按基金类型（股票型 / 指数型 / 混合型 / QDII / 债券型 / 货币型 / 其他）对持仓市值分组，分类按占比从高到低排列。鼠标悬停时对应扇区高亮、其余扇区淡化，并跟随鼠标指针在右下方浮出气泡展示类型、金额与占比（与图例一致的两位小数格式）。
- 新增基金类型识别 `FundType`：按官方 FTYPE 字段映射，在建仓 / 加减仓 / 转换 / 当日新增及手动刷新时抓取一次（行情刷新不再更新），并在主面板手动刷新时对存量持仓回填类型。

### 问题修复

- 修复 QDII 收益归属错位：QDII 基金（净值 T+1/T+2 披露）的当日收益现归到其净值更新当日，而非交易当日，避免收益日历与累计收益曲线出现错位的橙色待确认点。
- 修复收益日历在单只基金行情缺失时整体放弃记录的问题：改为仅跳过该基金（其对当日收益贡献本为 0），仅当所有活跃持仓行情均缺失时才不记录；同时确保当前交易日的本地实时计算优先覆盖已有记录，使当天收益日历与实时收益口径一致。
- 修复关闭自动更新后主界面仍提示「发现新版本 / 已是最新 / 检查失败」的问题：关闭自动更新即完全静默，仅保留用户主动发起的下载 / 安装进度提示。

### 功能优化

- 当日新买表单交互优化，录入更顺手。

## v1.0.1 - 2026-08-08

### 新功能

- 累计收益曲线支持鼠标悬停：移动鼠标实时显示垂直参考线、高亮数据点，以及该日的日期、累计收益、当日收益率与累计收益率。
- 收益曲线时间范围新增「1周」选项，可查看近 7 天收益走势与区间收益。
- 基金详情页改版：历史净值移入「净值业绩走势」页签，十大重仓股移入「盘中预估实时涨跌」页签，不再在底部一并平铺展示，改为跟随对应页签联动展示。
- 净值业绩走势页签切换近1月/近3月/近6月/近1年/近3年区间时，走势图上方新增展示相应区间的涨跌幅。

### 功能优化

- 收益曲线纵坐标补充累计收益率小字；隐藏金额模式下收益率仍可正常显示。
- 收益曲线左上角改为展示「区间收益」（区间内净赚金额），数值随所选区间变化，并按盈亏红绿着色。
